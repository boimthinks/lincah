## 1. Peta Ringkas 7 Koridor Utama dari Palembang

| Koridor | Arah | Urutan Daerah Kunci | Karakteristik Travel |
|---|---|---|---|
| **Utara** | Jambi | Talang Kelapa/Sembawa → Pangkalan Balai → Betung → Sungai Lilin → Bayung Lencir → Tempino → Jambi | Lintas Timur Sumatera, logistik & penumpang antarprovinsi |
| **Barat Laut** | Sekayu (Muba) | Ikut koridor Utara sampai Simpang Betung → Lais → Sekayu → Babat Toman → Sanga Desa → Mangunjaya | PNS Pemkab Muba, pekerja migas/tambang |
| **Barat / Tengah** | Muara Enim – Lahat – Lubuklinggau | Indralaya → Gelumbang → Prabumulih → Muara Enim → Tanjung Enim → Merapi → Lahat → Tebing Tinggi (Empat Lawang) → Lubuklinggau | Volume tertinggi: bisnis, tambang batu bara/migas, mahasiswa, lanjut Bengkulu |
| **Barat Daya** | Pagaralam | Ikut koridor Barat sampai Lahat → Pulau Pinang/Gumay Ulu → Kota Agung → Pagaralam | Wisata weekend, libur sekolah, keluarga (perkebunan teh Dempo) |
| **Selatan (OKU Raya)** | Baturaja – Martapura – Muaradua | Indralaya → Prabumulih → Rambang Dangku → Peninjauan → Baturaja → Martapura → Sender/Muaradua → Banding Agung (Danau Ranau) | Pedagang hasil bumi (kopi, karet), wisata Danau Ranau, mahasiswa/PNS |
| **Tenggara** | Kayu Agung (OKI) | Kertapati/Jakabaring → Pemulutan → Indralaya → Tanjung Raja → Teluk Gelam → Kayu Agung → Pedamarang | Komuter harian jarak dekat |
| **Pesisir Timur** | Tanjung Api-Api (Banyuasin) | Simpang Bandara SMB II / Jalan TAA → Gasing → Muara Telang → Pelabuhan TAA | Penyambung ferry ke Bangka (Tanjung Kalian/Muntok) |

> **Catatan strategis:** Koridor **Lintas Selatan (Palembang–Lampung via tol)** sengaja bukan fokus karena kompetisi sangat ketat. Koridor **Pesisir Timur (TAA)** punya potensi konten unik: travel door-to-door yang nyambung dengan tiket ferry ke Pulau Bangka.

## 2. Tiga Junction (Titik Percabangan) Utama

Ini titik temu rute — penting untuk navigasi web dan penjelasan jalur di artikel:

| Junction | Membelah Antara |
|---|---|
| **Simpang Indralaya (Timbangan)** | Jalur lurus/selatan → Tanjung Raja, Kayu Agung (Koridor Tenggara) VS belok barat → Gelumbang, Prabumulih (Koridor Barat & Selatan) |
| **Simpang Betung** | Lurus → Sungai Lilin, Jambi (Koridor Utara) VS belok → Lais, Sekayu (Koridor Barat Laut) |
| **Kota Prabumulih** | Barat → Muara Enim, Lahat, Lubuklinggau (Koridor Barat) VS selatan → Peninjauan, Baturaja, Martapura, Muaradua (Koridor OKU Raya) |

Struktur percabangan presisi dari Palembang: **satu** Simpang Indralaya saja (bukan dua), lalu Prabumulih memecah lagi dua arah.

## 3. Detail Titik per Koridor (Referensi Menulis)

### Koridor Utara (Palembang–Jambi)
Palembang (KM12/Alang-Alang Lebar) → Banyuasin: Talang Kelapa (Sembawa), Pangkalan Balai (ibukota Banyuasin), Suak Bara, Betung → Muba: Sungai Lilin, Tungkal Jaya, Bayung Lencir (batas Sumsel-Jambi) → Jambi: Tempino (Muaro Jambi), Kota Jambi.

### Koridor Barat Laut (Palembang–Sekayu)
Mengikuti Utara sampai Simpang Betung → Muba: Lais → Sekayu (ibukota Muba) → Babat Toman → Sanga Desa → Mangunjaya (dapat lanjut Lubuklinggau via Jalur Tengah).

### Koridor Barat/Tengah (Palembang–Lubuklinggau)
Ogan Ilir: Indralaya (Simpang Timbangan/exit tol) → Muara Enim timur: Gelumbang, Lembak → Kota Prabumulih: Cambai → Muara Enim: Gunung Megang, Muara Enim Kota, Tanjung Enim (tambang PTBA) → Lahat: Merapi, Lahat Kota → Empat Lawang: Tebing Tinggi → Lubuklinggau (hub menuju Curup/Bengkulu).

### Koridor Barat Daya (Palembang–Pagaralam)
Ikut Barat sampai Lahat Kota → cabang: Pulau Pinang/Gumay Ulu → Kota Agung → Pagaralam (kawasan perkebunan teh Gunung Dempo).

### Koridor Selatan OKU Raya (Palembang–Muaradua)
Indralaya → Prabumulih → OKU: Rambang Dangku, Peninjauan, Baturaja (ibukota OKU) → OKU Timur: Martapura → OKU Selatan: Muaradua (ibukota) → Banding Agung (Danau Ranau).

### Koridor Tenggara (Palembang–Kayu Agung)
Palembang: Kertapati/Jakabaring → Ogan Ilir: Pemulutan, Indralaya, Tanjung Raja → OKI: Teluk Gelam, Kayu Agung (ibukota OKI), Pedamarang.

### Koridor Pesisir Timur (Palembang–TAA)
Palembang: Simpang Bandara SMB II/Jalan TAA → Banyuasin: Gasing, Muara Telang, Pelabuhan Tanjung Api-Api (ferry ke Tanjung Kalian, Muntok, Bangka).

## 4. Aturan Pakai untuk Konten

1. **Akurat geografis** — saat artikel menyebut "melewati apa saja", ikuti urutan di atas. Dilarang menebak-nambah kecamatan.
2. **Internal link sekoridor** — artikel dalam koridor sama saling terkait: mis. artikel Lahat ↔ Pagaralam ↔ Tebing Tinggi ↔ Pendopo Lintang (satu koridor Barat); Betung ↔ Sungai Lilin ↔ Bayung Lencir ↔ Sekayu ↔ Jambi (koridor Utara/Barat Laut).
3. **Angle lokal dari karakteristik** — koridor Barat = pekerja tambang/dinas; Barat Daya = wisata; Selatan = pedagang kopi/karet & Danau Ranau; Tenggara = komuter; Pesisir Timur = penyambungan ferry Bangka.
4. **Zona penjemputan** — deskripsi layanan door-to-door boleh merujuk kecamatan di koridor tujuan.
5. **Junction sebagai pembeda artikel** — mis. "via Simpang Betung atau lewat jalur pesisir?" bisa jadi angle perbandingan.
